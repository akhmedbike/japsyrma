# japsyrma — редактор этикеток для TSC TE200

Легкий редактор этикеток для термопринтеров TSC TE200 и совместимых (язык TSPL).
Wails v2 (Go) + Svelte 5 + Konva. Печать — RAW-задание TSPL через спулер Windows.

## Возможности

- **Текст** — системные шрифты, размер в пунктах, выравнивание, поворот.
- **Изображения** — нативный диалог выбора файла, вставка обводкой области прямо на этикетке; перевод в ч/б: растрирование (фото) или порог (логотипы), яркость/контраст/негатив.
- **Штрихкоды** — Code 128, EAN-13, QR и другие (bwip-js), размер модулем, проверка корректности значения перед печатью.
- **Фигуры** — рамка, линия, эллипс, треугольник; контур или черная заливка.
- **Превью «как напечатается»** — 1-битный растр ровно в точках принтера.
- **Диагностика печати** — пошаговая проверка пути задания: драйвер, порт, режим «работать автономно», застрявшие задания в очереди, пробное пустое RAW-задание, журнал последней попытки; кнопки открытия очереди Windows и отмены всех заданий. Опрос спулера — напрямую через winspool, без PowerShell.
- **Слежение за заданием** — после отправки на печать приложение следит, как задание проходит очередь: подтверждает передачу в порт принтера и предупреждает, если оно застряло или упало с ошибкой.
- **Экспорт** — PNG и PDF в натуральном размере, задание .prn, пробный оттиск на обычном принтере.
- **Шаблоны** `.label` (JSON) — открытие/сохранение, список недавних файлов, путь в заголовке окна.
- **Редактирование** — отмена/повтор (Ctrl+Z / Ctrl+Shift+Z), копирование/вставка/вырезание элементов (Ctrl+C/V/X), дублирование (Ctrl+D), порядок выше/ниже, стрелки для сдвига.
- Нативное меню (macOS), тосты о выполнении действий, окно подстраивается под маленькие экраны.

На macOS и Linux доступно редактирование и экспорт; печать — только на Windows (спулер, RAW).

## Сборка и запуск

```
go install github.com/wailsapp/wails/v2/cmd/wails@latest
cd japsyrma
go get github.com/wailsapp/wails/v2@latest github.com/alexbrainman/printer@latest
go mod tidy

wails dev                          # разработка с горячей перезагрузкой
wails build                        # macOS: build/bin/japsyrma.app
wails build -platform windows/amd64  # Windows: build/bin/japsyrma.exe
```

- `wails dev` сам выполнит `npm install` и сгенерирует `frontend/wailsjs` (JS-обертки Go-методов).
- Для кросс-компиляции .exe из macOS/Linux нужен `mingw-w64` (`brew install mingw-w64`).
- Иконка приложения — `build/appicon.png`, иконка exe — `build/windows/icon.ico`.

## Устройство

- `main.go` — окно и нативное меню (пункты шлют события `menu:*` во фронтенд).
- `app.go` — методы для фронтенда: принтеры, печать, прогон, экспорт, шаблоны, выбор изображения; подгонка окна под экран.
- `printer_windows.go` / `printer_other.go` — RAW-печать через спулер Windows / запись в /dev/usb/lpN.
- `internal/tspl`, `internal/imaging` — генерация TSPL-заданий и работа с растром (из утилиты labelspike).
- `frontend/src/lib/state.svelte.js` — состояние документа, история отмены, буфер обмена элементов.
- `frontend/src/lib/editor.js` — сцена Konva: 1 единица = 1 точка принтера; выделение, трансформации, режим обводки области.
- `frontend/src/lib/mono.js` — перевод изображений в 1 бит, финальный порог этикетки.
- `frontend/src/lib/barcode.js` — генерация штрихкодов.
- Шаблон `.label` — JSON; изображения хранятся внутри как data URL.
